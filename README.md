# Menu QR | Biloa House

Menu digital mobile du Biloa House (Yaoundé) : Restaurant, Café, Boutique, Infos.
Maquette de démonstration réalisée par INNOVA ALPHA.

- `index.html` : le menu (ouvert par le QR code des tables)
- `plaque-qr.html` : la plaque QR à imprimer, qui pointe vers ce menu

Lien de test : https://thaddee12.github.io/menu-biloa-house/
